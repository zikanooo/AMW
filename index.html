Rencana ke depan

Untuk sekarang, AXE MOTION dikembangkan sebagai aplikasi berbasis web karena lebih cepat untuk melakukan eksperimen, mencoba fitur baru, dan mengubah sistem editor.

Ke depannya, ada rencana untuk membuat versi aplikasi native, termasuk APK Android, setelah Opus Framework dirilis dan kondisinya sudah cukup matang untuk digunakan.

Apa itu Opus Framework?

Opus adalah framework video timeline composition berbasis Kotlin Multiplatform yang sedang dikembangkan oleh The Prismatic Company, yang juga melibatkan pengembang yang sebelumnya pernah mengerjakan Alight Motion.

Secara sederhana, Opus menyediakan fondasi untuk membuat aplikasi yang berhubungan dengan video dan motion graphics. Framework ini dirancang untuk menangani video, audio, gambar, teks, compositing, animasi, efek visual, timeline multimedia, preview, rendering, export, serta berbagai kebutuhan media lainnya.

Cara kerjanya memakai pendekatan yang mirip dengan Jetpack Compose / Compose Multiplatform, sehingga timeline dan elemen media dapat bereaksi terhadap perubahan state secara real-time saat pengguna melakukan editing.

Opus juga sudah memperlihatkan dukungan untuk ruang 3D seperti posisi X, Y, Z, kamera, parallax, dan rotasi tiga dimensi, serta API tingkat rendah untuk GPU rendering dan custom shader GLSL.

Kenapa AXE MOTION tertarik memakai Opus?

Karena tujuan AXE MOTION bukan hanya menjadi editor video biasa. AXE MOTION direncanakan berkembang menjadi editor motion graphics, animation, compositing, dan 3D.

Opus bisa menjadi fondasi mesin multimedia AXE MOTION untuk menangani timeline, decoding video/audio, playback, compositing, animasi, efek, filter, GPU rendering, export video, serta sistem 3D dan kamera.

Kalau Opus nantinya memang cocok, AXE MOTION tidak perlu membangun seluruh engine multimedia dari nol. Pengembangan bisa lebih fokus pada bagian yang benar-benar membentuk identitas AXE MOTION: UI editor, keyframe, timeline, workflow animasi, tools, efek, dan fitur kreatif lainnya.

Opus berbasis Kotlin Multiplatform dan dirancang untuk digunakan di beberapa platform. Pada materi pengembangnya, iPhone, iPad, dan macOS sudah didukung, sementara Android dan Windows masih dalam pengembangan. Dukungan Web dan backend juga direncanakan.

Opus juga direncanakan menjadi open source, tetapi saat ini masih dipersiapkan sebelum dirilis secara publik.

Belum keputusan final

Opus belum tentu menjadi engine final AXE MOTION. Setelah framework-nya benar-benar dirilis, baru bisa dilihat apakah performa, fitur, kompatibilitas, lisensi, dan arah pengembangannya cocok dengan kebutuhan AXE MOTION.

Untuk sekarang, AXE MOTION akan tetap berkembang sebagai proyek eksperimen sambil terus membangun fitur dan mencoba berbagai ide.

Terima kasih sudah mencoba AXE MOTION dan ikut melihat perkembangannya dari tahap awal.
